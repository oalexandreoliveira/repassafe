# Estratégia de testes

Vitest cobre unidades e integração leve; Playwright cobre o smoke test móvel; pgTAP valida RLS com responsável, candidato, aprovador, não membro e anônimo. O CI verifica tipos, lint, formato, escopo, segredos, auditoria estática de segurança, build, dependências, E2E e a suíte SQL em banco descartável.
